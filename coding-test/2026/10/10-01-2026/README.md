# median finding(중앙값 구하기)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

- 정수 배열 array를 크기순으로 정렬했을 때, 가장 가운데에 있는 값인 중앙값을 반환하는 함수를 작성한다.

### 제한 사항

- array의 길이는 홀수이다.
- 0 < array의 길이 < 100
- -1,000 < array의 원소 < 1,000

### 입출력 예

| array               | result |
| ------------------- | ------ |
| `[1, 2, 7, 10, 11]` | `7`    |
| `[9, -1, 0]`        | `0`    |

### 입출력 예 설명

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   - 정수가 들어 있는 배열이 있고, 배열의 길이는 항상 홀수이다.

2. 그래서 뭘 해야 하는지 보기
   - 배열을 오름차순으로 정렬하고 가운데 값의 인덱스를 구해야한다.
   - 배열의 인덱스는 0부터 시작하고, 길이가 5면 가운데 인덱스는 2이다.
   - math.floor(array.length/ 2)로 값을 구할 수 있다

3. 어떤 값을 출력해야 하는지 보기
   - 정렬한 배열에서 가운데 인덱스에 있는 값을 반환한다.

4. 코드작성

## 회고

중앙값은 배열을 정렬한 다음 찾아야 한다.
숫자 정렬에는 sort((a, b) => a - b)를 사용한다.
sort()는 원본 배열을 직접 변경한다.
배열의 인덱스는 0부터 시작하고, 가운데 인덱스와 그 위치에 있는 값을 구분해야 한다.
