# Double Array Elements (배열 두 배 만들기)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

정수 배열 `numbers`가 매개변수로 주어집니다.
`numbers`의 각 원소를 두 배로 만든 배열을 반환하는 `solution` 함수를 작성합니다.

### 제한 사항

- `-10,000 ≤ numbers`의 원소 `≤ 10,000`
- `1 ≤ numbers`의 길이 `≤ 1,000`

### 입출력 예

| numbers                     | result                       |
| --------------------------- | ---------------------------- |
| `[1, 2, 3, 4, 5]`           | `[2, 4, 6, 8, 10]`           |
| `[1, 2, 100, -99, 1, 2, 3]` | `[2, 4, 200, -198, 2, 4, 6]` |

### 입출력 예 설명

#### 예제 1

`[1, 2, 3, 4, 5]`의 각 원소에 2를 곱하면 `[2, 4, 6, 8, 10]`이 됩니다.

#### 예제 2

`[1, 2, 100, -99, 1, 2, 3]`의 각 원소에 2를 곱하면 `[2, 4, 200, -198, 2, 4, 6]`이 됩니다.

## 접근 방법

### 1. 뭐가 입력으로 들어오는지 보기

- 정수들이 담긴 배열 `numbers`

### 2. 그래서 뭘 해야 하는지 보기

- 배열을 처음부터 끝까지 순회하고
- 각 원소에 2를 곱한다음
- 계산한 값을 새로운 배열의 같은 위치에 저장한다

### 3. 어떤 값을 출력해야 하는지 보기

- `numbers`의 모든 원소를 두 배로 만든 새로운 정수 배열을 반환해야한다.
- 입력 배열과 결과 배열의 길이는 같다

### 4. 코드 작성

- 'solution.js' 참고

## 해석

`map()`은 배열의 원소를 처음부터 끝까지 하나씩 꺼내 주어진 작업을 실행하고, 그 결과로 새로운 배열을 만드는 메서드이다.

```javascript
numbers.map((number) => number * 2);
```

이 코드에서 `number`에는 `numbers`의 원소가 하나씩 들어옵니다. 각 원소에 2를 곱한 값이 새로운 배열에 차례대로 저장된다.

결과 배열을 위한 공간은 자바스크립트가 알아서 관리하며, `map()`이 입력 배열과 같은 길이의 새로운 배열이 생긴다.

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(n)`

## 회고

배열의 모든 원소를 같은 규칙으로 바꿀 때 자바스크립트의 `map()`을 사용할 수 있다는 것을 배웠고, 반복문으로 직접 결과 배열에 값을 넣을 수도 있지만, `map()`을 사용하면 각 원소를 변환해 새로운 배열을 만든다는 의도를 더 간결하고 분명하게 표현할 수도 있다.
