# Add Fractions (분수의 덧셈)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

첫 번째 분수의 분자와 분모를 뜻하는 `numer1`, `denom1`, 두 번째 분수의 분자와 분모를 뜻하는 `numer2`, `denom2`가 주어진다.
두 분수를 더한 값을 기약분수로 나타냈을 때 분자와 분모를 순서대로 담은 배열을 return한다.

### 제한 사항

- 0 < `numer1`, `denom1`, `numer2`, `denom2` < 1,000

### 입출력 예

| numer1 | denom1 | numer2 | denom2 | result  |
| -----: | -----: | -----: | -----: | ------- |
|      1 |      2 |      3 |      4 | [5, 4]  |
|      9 |      2 |      1 |      3 | [29, 6] |

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   - 숫자 자료형(Number)
   - 첫 번째 분수의 분자 `numer1`
   - 첫 번째 분수의 분모 `denom1`
   - 두 번째 분수의 분자 `numer2`
   - 두 번째 분수의 분모 `denom2`

2. 그래서 뭘 해야 하는지 보기
   1. 분자 계산
      `(numer1 * denom2) + (numer2 * denom1)`
   2. 분모 계산
      `denom1 * denom2`
   3. 최대공약수를 저장할 변수를 만들고, 1부터 하나씩 나눠보기
   4. 분자와 분모 둘다 나누어 떨어지는 가장 큰 수 찾기
   5. 분자와 분모를 그 수로 나누기
   6. [분자, 분모] return

3. 어떤 값을 출력해야 하는지 보기
   - 기약분수의 분자와 분모를 `[분자, 분모]` 형태의 배열로 return한다.

4. 코드작성
   - solution.js 참고

## 회고

이번 문제는 분수의 덧셈 문제로,
분자와 분모를 계산하여 나온 두 수의 공약수를 for문을 통해 찾고,
가장 큰 공약수로 분자와 분모를 나누어 나온 값을 반환하는 문제였다.
이 문제가 수학에서 간단하게 진행하면 계산할 수 있는데, 코드로 작성하려고 보니까 너무 헷갈렸다.
최대공약수를 저장할 변수를 만들고 1부터 하나씩 확인하는 과정인 for 문과 최대공약수를 구하는 if문의 코드를 여러번 작성해보며 어떻게 코드로 작성해야하는건지 차근차근 접근해봤다.
for문
` for (let i = 1; i <= numer3 && i <= denom3; i++)`
if문
`if (numer3 % i === 0 && denom3 % i === 0) {gcd = i;}`

이번 문제에 쓴 연산자
% → 나머지
=== 0 → 나누어떨어지는지 확인
&& → 그리고
