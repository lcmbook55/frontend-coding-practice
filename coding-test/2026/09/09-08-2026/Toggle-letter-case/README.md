# Toggle letter case

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

영어 알파벳으로 이루어진 문자열 str이 주어집니다. 각 알파벳을 대문자는 소문자로 소문자는 대문자로 변환해서 출력하는 코드를 작성해 보세요.

### 제한 사항

- 1 ≤ str의 길이 ≤ 20
- str은 알파벳으로 이루어진 문자열입니다.

### 입출력 예

- 입력
  `aBcDeFg`

- 출력
  `AbCdEfG`

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   대소문자 문자열

2. 그래서 뭘 해야 하는지 보기
   - 결과를 담을 빈 문자열 생성`(let str = '')`
   - str.length 까지 for문으로 문자열 순회
   - str[i]를 사용해 한 글자씩 확인
   - 대문자인지 소문자 인지 반별 후 변환
   - 대소문자 변환 메서드 사용(.toUpperCase()/.toLowerCase())
     대문자는 소문자로 변환
     소문자는 대문자로 변환
   - 변환한 문자열을 result에 하나씩 추가

3. 어떤 값을 출력해야 하는지 보기
   - 대문자와 소문자가 반대로 변환된 문자열 출력

4. 코드작성
   - solution

## 회고

처음에는 문자열 전체를 .toUpperCase() 또는 .toLowerCase()로 바꾸려고 했지만. 이번 문제는 문자열을 한 글자씩 순회하면서 현재 문자가 대문자인지 소문자인지 확인한 뒤 반대로 바꿔서 출력하는 문제였다.

이번 문제를 통해 str.length, str[i], .toUpperCase(), .toLowerCase()를 이용하여 문자열을 순회하고 변환하는 방법을 배웠다.

아직 아래 연산자들이 약간 헷갈린다.
=== // 두 값이 같은지 비교 연산자
+= // 기존 값에 더해서 다시 저장하는 연산자
< // 왼쪽 값이 오른쪽 값보다 작은지 비교 연산자
문법 자체는 이해했지만. 기본 연산자를 코드 안에서 빠르게 해석하는 연습이 더 필요하다고 느꼈다.
