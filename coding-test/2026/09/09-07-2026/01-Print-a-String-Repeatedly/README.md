# Print a String Repeatedly (문자열 반복해서 출력하기)
- 출처: Programmers
- 난이도: Lv.0

## 문제 설명
문자열 str과 정수 n이 주어집니다.
str이 n번 반복된 문자열을 만들어 출력하는 코드를 작성해 보세요.

### 제한 사항
  - 1 ≤ str의 길이 ≤ 10
  - 1 ≤ n ≤ 5

### 입출력 예
  - 입력
    - string 5
  
  - 출력
    - stringstirngstringstirngstirng


## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
    - 문자열과 숫자를 입력받는다.
2. 그래서 뭘 해야 하는지 보기
   - 문자열을 n번 반복한다.
3. 어떤 값을 출력해야 하는지 보기
   - 반복된 문자열을 출력한다.


4. 코드작성

- solution 1.  repeat() 사용
  - JavaScript의 문자열 메서드인 repeat()을 사용하면 문자열을 원하는 횟수만큼 반복할수 있다.
  - console.log() 를 close 함수 밖에 작성해서 ReferenceError 발생!
  - str 과 n은 함수 안에서 선언했기 때문에 같은 범위 안에서 사용해야한다.

- solution 2. Using a for Loop (반복문 for 사용)

## 해석
입력, 타입변환, 문자열 메서드, 반복문, 스코프
  - line.split(' ') 공백을 기준으로 입력값을 나눔
  - Number(input[1]) 문자열로 들어온 숫자를 -> 숫자 타입으로 변환해줌
  - str.repeat(n) 문자열 n을 반복
  - for (let i = 0; i < n; i++>) for문으로 문자열 누적하며 반복


## 회고
이번 문제는 문자열을 반복해서 출력하는 간단한 문제였다.

처음에는 repeat()메서드를 사용해서 풀었지만 str ,n이 close함수 안에서 선언되었지만 console.log()출력을 함수 밖에서 진행하여 ReferenceError라 발생되었다.

이 과정에서 변수는 선언된 블록의 범위에 따라 사용할 수 있는 위치가 달라진다는 스코프(scope)개념을 다시 익혔다. 자꾸 까먹는다..

repeat()을 사용하면 간단하게 문자열을 반복할 수 있고, for문을 사용해서 문자열을 하나씩 누적하는 방식으로도 문제를 풀 수 있다는 것을 확인했다.
