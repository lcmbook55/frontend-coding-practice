# Print a and b(a와b 출력하기)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

- 정수 a와 b가 주어집니다. 각 수를 입력받아 입출력 예와 같은 형식으로 출력하는 코드를 작성해 보세요.

### 제한 사항

- -100,000 ≤ a, b ≤ 100,000

### 입출력 예

- 입력 #1
  `4 5`
- 출력 #1
  `a = 4`
  `b = 5`

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   - `4 5`
   - 두 정수가 공백으로 구분되어 한 줄로 입력됨

2. 그래서 뭘 해야 하는지 보기
   - 입력값을 공백 기준으로 나눈다.
   - 각 값을 `a = 값`, `b = 값` 형식으로 출력한다.

3. 어떤 값을 출력해야 하는지 보기
   - `a = 4`
   - `b = 5`

4. 코드작성

## 회고

- `input = line.split(' ');` 을 통해 입력값이 공백으로 구분되어야 한다는 것을 다시 확인했다.
- `split()`으로 나누면 문자열로 들어오게된다.
- 문자열 안에 변수값을 넣을때는 `${input[0]}`를 사용하여 출력해야 한다.

## 해석

input[0] → 배열의 첫 번째 값
split(' ') → 공백 기준으로 문자열 나누기
`${변수}` → 문자열 안에 변수값 넣기
console.log() → 출력
Number() → 문자열 숫자를 진짜 숫자로 변환

### 런타임 에러 나면 제일 먼저 볼것

- 함수명 오타
- 변수명 오타
- 괄호 (), {}, []
- 따옴표 / 백틱
- 선언 안 한 변수
