# Find the Remainder (나머지 구하기)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

정수 `num1`, `num2`가 매개변수로 주어질 때, `num1`을 `num2`로 나눈 나머지를 반환하는 `solution` 함수를 작성합니다.

### 제한 사항

- `0 < num1 ≤ 100`
- `0 < num2 ≤ 100`

### 입출력 예

| num1 | num2 | result |
| ---: | ---: | -----: |
|    3 |    2 |      1 |
|   10 |    5 |      0 |

### 입출력 예 설명

#### 예제 1

3을 2로 나누면 몫은 1이고 나머지는 1이므로 `1`을 반환합니다.

#### 예제 2

10을 5로 나누면 나머지가 없으므로 `0`을 반환합니다.

## 접근 방법

### 1. 뭐가 입력으로 들어오는지 보기

- 두 개의 정수 `num1`, `num2`가 들어옴

### 2. 그래서 뭘 해야 하는지 보기

- `num1`을 `num2`로 나누기
- 나눈 결과의 몫이 아니라 나머지를 구하는 문제이다.
- 자바스크립트의 나머지 연산자 `%`를 사용합니다.

### 3. 어떤 값을 출력해야 하는지 보기

- `num1`을 `num2`로 나눈 나머지를 반환한다.

### 4. 코드 작성

`solution.js` 참고

## 해석

`%`는 왼쪽 숫자를 오른쪽 숫자로 나눈 뒤, 남은 값을 구하는 나머지 연산자이다.

## 회고

두 수를 나눈 나머지는 `%` 연산자로 간단하게 구할 수 있다는 것을 확인했다. 문제에서 요구하는 값이 몫인지 나머지인지 정확하게 구분하는 것이 중요하다. 앞으로 어떤 수가 다른 수로 나누어떨어지는지 확인할 때도 `%` 연산자를 활용할 수 있다.
