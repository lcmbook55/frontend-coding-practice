# Find The Quotient (몫 구하기)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

정수 num1과 num2가 매개변수로 주어질 때, num1을 num2로 나눈 몫을 retrun하도록 solution 함수를 완성해주세요.

### 제한 사항

-50,000 ≤ num1 ≤ 50,000
-50,000 ≤ num2 ≤ 50,000

### 입출력 예

| num1 | num2 | result |
| ---- | ---- | ------ |
| 10   | 5    | 2      |
| 7    | 2    | 3      |

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   - num1을 num2로 나눈 몫

2. 그래서 뭘 해야 하는지 보기
   - `num1`에서 `num2`를 `/`연산자를 사용하여 나눈다.
   - 몫을 소수점없이 정수로 반환한다.

3. 어떤 값을 출력해야 하는지 보기
   - `num1 - num2`의 결과를 return해준다.

4. 코드작성
   - solution.js 참고

## 회고

정수를 변환하기 위한 함수 parseInt()로도 같은 결과를 낼 수 있지만, 숫자가 커지게되면 문제가 생길 수 있다.
이번 문제는 두 수를 나눈 결과에서 소수점 이하를 제거하고 정수 몫을 반환해야 하므로 Math.floor()함수를 사용하는 것이 문제의 의도에 더 적합하다.
하지만, 처음에 소수점을 제거하는 함수인줄 알았지만 찾아보니 "내림"함수이며
현재 문제에서는 양수의 몫을 구하는 상황에서는 사실상 소수점 이하를 버리는 것으로 보이기도하다.

- Math.floor() 함수 사용 예시(소수점 이하 내림)
  `Math.floor(3.7)` // 3
  `Math.floor(-3.7)` // -4
