# Multiply Two Numbers (두 수의 곱 구하기)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

정수 num1, num2가 매개변수 주어집니다. num1과 num2를 곱한 값을 return 하도록 solution 함수를 완성해주세요.

### 제한 사항

- 0 ≤ num1 ≤ 100
- 0 ≤ num2 ≤ 100

### 입출력 예

- 입력
  `num1 = 3, num2 = 4`

- 출력
  `12`

- 입력
  `num1 = 27, num2 = 19`

- 출력
  `513`

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   - 정수 `num1`, `num2`

2. 그래서 뭘 해야 하는지 보기
   - num1과 num2를 곱한다.
   - 곱셈 연산자 \* 사용
   - 곱한 값을 answer에 저장

3. 어떤 값을 출력해야 하는지 보기
   - `num1 * num2`의 결과값을 return

4. 코드작성
   - solution

## 회고

이번 문제는 두 개의 정수를 입력받아 곱셈 연산자 `*`를 사용하여 결과를 반환하는 아주아주 간단한 문제다!

`num1`과 `num2`는 solution 함수의 매개변수로 들어오고, 두 값을 곱한 결과를 `answer`에 저장한 뒤 return하면 된다.

이번 문제를 통해 함수의 매개변수로 값을 받아 연산하고, 결과를 return하는 기본적인 구조를 다시 연습했다.

문제 풀면서 콘솔로그와 리턴이 정말 잠깐 헷갈렸다. `return`과 `console.log()` 두 개의 차이를 확실하게 알아한다.

- `return` // 함수의 결과값을 반환
- `console.log()` // 값을 화면에 출력
- `*` // 두 값을 곱하는 곱셈 연산자
