# Compare Two Numbers (숫자 비교하기)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

정수 num1과 num2가 매개변수로 주어집니다. 두 수가 같으면 1 다르면 -1을 return하도록 solution 함수를 완성해주세요.

### 제한 사항

0 ≤ num1 ≤ 10,000
0 ≤ num2 ≤ 10,000

### 입출력 예

| num1 | num2 | result |
| ---- | ---- | ------ |
| 2    | 3    | -1     |
| 11   | 11   | 1      |
| 7    | 99   | -1     |

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   - 숫자 자료형(number)
   - `num1` 과 `num2`의 값을 비교한다.

2. 그래서 뭘 해야 하는지 보기
   - `num1`에서 `num2`를 비교한다.
   - 비교연산자 `===`를 사용한다.(둘 다 number)
   - 입출력 예시에 음수는 없으므로 양수로만 비교한다.
   - if,else 문으로 처리 가능하다.
   - 같으면 1, 다르면 -1 으로 반환한다.

3. 어떤 값을 출력해야 하는지 보기
   - `num1` 과 `num2` 값을 비교하여 같으면 1, 다르면 -1를 return해준다.

4. 코드작성
   - solution.js 참고
   - 더 간단한 코드(삼항 연산자 사용)
   ```
   function solution(num1, num2)
   {
      var answer = num1 === num2 ? 1 : -1; // 삼항 연산자 사용
      return answer;
   }
   ```

## 회고

이번 문제는 조건과 비교연산자, 삼항 연산자를 사용하여 풀수 있는 문제였다.
비교적 쉬웠던 문제이지만 내가 간과했던 부분은 결과값을 담는 변수에 먼저 초기값을 넣어주는 것.
조건에 따라 값을 재할당 해주는 부분을 다시 한번 기억하자.

- 삼항 연산자
  삼항 연산자는 조건에 따라 서로 다른 값을 반환하는 조건 연산자 이다.
  간단한 `if...else` 문을 한줄로 줄여서 쓸 때 사용한다.
  형식 - 조건식 ? 참일 때 값 : 거짓일 때 값
