# Divide Two Numbers (두 수의 나눗셈)

- 출처: Programmers
- 난이도: Lv.0

## 문제 설명

정수 `num1`과 `num2`가 매개변수로 주워질 때, `num1`을 `num2`로 나눈 값에 1,000을 곱한 후 정수 부분을 return하도록 solution 함수를 완성해주세요.

### 제한 사항

0 < num1 <= 100
0 < num2 <= 100

### 입출력 예

| num1 | num2 | result |
| ---- | ---- | ------ |
| 3    | 2    | 1500   |
| 7    | 3    | 2333   |
| 1    | 16   | 62     |

### 입출력 예 설명

입출력 예 #1

- `num1`이 3, `num2`가 2이므로 3 / 3 = 1.5에 1,000을 곱하면 15000이 됩니다.
  입출력 예 #2
- `num1`이 7, `num2`가 3이므로 7 / 3 = 2.3333...에 1,000을 고하면 2333.3333...이 되며, 정수 부분은 2333입니다.
  입출력 예 #1
- `num1`이 , `num2`가 16이므로 1 / 16 = 0.0625에 1,000을 곱하면 62.5가 되며 정수 부분은 62입니다.

## 접근 방법

1. 뭐가 입력으로 들어오는지 보기
   숫자 자료형(Number)
   - 정수 `num1`
   - 정수 `num2`

2. 그래서 뭘 해야 하는지 보기
   - `num1`에서 `num2`를 나눈다.
   - 나눈 값에 `*`연산자를 사용하여 1000을 곱해준다.
   - 소수점 이하를 버리고 정수 부분만 추출한다.

3. 어떤 값을 출력해야 하는지 보기
   - `num1` / `num2` \* 1000의 결과를 return해준다.

4. 코드작성
   - solution.js 참고

## 회고

Math.trunc(2333.333) // 2333
Math.floor(2333.333) // 2333
두개의 매서드의 결과는 같다.
하지만 차이는 음수에서 생긴다.
Math.trunc(-2.7) // -2 // 소수점 이하를 그냥 제거해준다.
Math.floor(-2.7) // -3 // 더 작은 정수로 내린다.

이번 문제에서는 결과가 음수가 될 일이 없어서 둘 중 어느것을 써도 무관하지만,
문제에 입출력 예에서 음수가 나왔다면 Math.trunc()메서드를 사용하는것이 정확하다.

- 정수를 반환하는 `Math` 객체의 메서드
  Math.floor() // 소수점 내림
  Math.ceil() // 소수점 올림
  Math.round() // 소수점 반올림
  Math.trunc() // 소수점 이하 버림
- 전역에서 바로 호출하는 함수
  ParseInt() // 값을 정수로 변환(주로 문자열을 정수로 바꿀때 사용)

- 한 줄 정리
  floor 내림 / ceil 올림 / round 반올림 /trunc 버림 / parseInt 문자열 정수 변환
